shorts-factory: Privacy Policy

shorts-factory is a private tool used only by its owner to upload and schedule videos to their own YouTube channel.

What it accesses: it uses the YouTube Data API to upload videos and read the name of the logged-in channel. It does not access any other Google data.

What it stores: a login token and the channel ID are stored only on the owner's computer. Nothing is sent to any server other than YouTube, and no data is sold, shared or used for advertising.

Other users: the tool is not offered to the public and collects no data from anyone else.

Removing access: access can be revoked at any time at myaccount.google.com/permissions.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
